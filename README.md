# Ripple Effect Forward

Build a sleek, single-page React+Vite web app for Github hosting themed "The Future Starts Here," centered on "The Ripple Effect". The site visualizes how small actions trigger cascading future consequences through interactive, expanding circular wave animations.


Visual System & Accessibility:

Follow Google Material Design principles, strict W3C WCAG 2.1 AA accessibility standards (keyboard navigation, high contrast ratio, ARIA screen-reader regions). Strictly adhere to the ASD-STE100 Simplified Technical English standard when writing descriptions. The background features a soothing, dynamic Perlin noise canvas animation using a custom earthy-green palette (#52796f, #354f52, #2f3e46). Avoid generic AI-generated aesthetics by employing custom modern typography, subtle elevation, tactile micro-interactions.


Architecture & Regex Engine:

	Fully client-side with zero backend required. Embed a robust, extensive, multi-rule JavaScript Regex dataset and fuzzy key-phrase dictionary that:

	Filters out and rejects irresponsible, harmful, or unpleasant actions with a gentle corrective UI notification ripple.

	Dynamically parses positive custom inputs (e.g., "Plant a tree", "Compost food waste") into 6–7 sequential consequence nodes with expanding visual ripples.


Interface Layout:

Features a centered glassmorphic prompt input bar, interactive Canvas/SVG visualizer showing branching outcome chains, an accessible collapsible side drawer displaying text impact breakdowns.
